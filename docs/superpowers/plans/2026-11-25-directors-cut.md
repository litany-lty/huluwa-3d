# 葫芦兄弟九幕导演重剪实施计划

目标：将偏特效展示的 44 个旧镜头逐一改成读得懂的角色动作；不改变原有九幕剧情、240 秒正片时间线、18 秒片头与 34 秒片尾交付时基。允许重排幕内镜头及压低冗余字幕；原片保留，不改主分支。试剪已批准为参照，尤其修正走路滑动和蝎子击中接触点。

- [ ] 动作基础：由实走距离驱动左右支撑脚，原地停止时无脚滑；以单一函数从时间和位置求锚点，可重复 seek。着力、止步、触物和反作用逐段定点，不把统一滤镜视作改动画。
- [ ] 壹到叁：开场走路→钻山→营救→栽种→遇袭；大娃落地、抬石、砸中、追蛇、陷入泥潭；二娃观察、发现、识破、受伤、穿山甲护送坠落，保留方向和时间顺序。
- [ ] 肆到陆：门先接触后开，针/斧/镜子断在相应动作；柔剑先接触后收紧，脸与脚不过曝；火/水错开释放，饮酒、顾望、结冰；六娃隐身追踪、花的转移、两妖真实相撞、如意从台座到手、救人。
- [ ] 柒到玖：七娃的鞠躬与挥葫芦分别处理，六人逐一被吸，完整入炉；接入新版莲花试剪并修正走路和蝎尾；七人落地接向最后一幕，面向敌人，再结阵镇妖、山峰与静帧收束。
- [ ] 素材与权利：音轨沿用 03–09 原始器乐，按原速原调重混，音效只用仓库，视频与原始 WAV 不入 Git，不发布。
- [ ] 验收：关键姿态和状态在同一时刻正向播放与跳转一致，着力/接触/出手分别截图逐幕看；至少一轮九幕动画采样，之后成片一次解码、音视频长度、段落连接、关键声音落点。交付全片和一个短预览。
