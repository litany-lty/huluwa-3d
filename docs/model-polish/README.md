## 文件与验收

- 48 个 GLB 从 31,481,500 降至 28,926,212 字节（约 8.1%）。角色 RGB 色图使用高质量 JPEG；法线及材质参数贴图保留 PNG。原有贴图分辨率、RGBA 遮罩、节点、位置、索引、UV、变形接口全保留。新增岩石与木纹法线仅改变阴影，不改模型轮廓。
- [加载审查](verified-loads.json)：电影实际加载 48 个模型，不把贴图回退当成功。对照版渲染 26 个影片检查点，演员组、位置、旋转及取样变形与原剪辑一致。例：片头七只葫芦、三娃位于宴桌前、五娃越过碗沿、片尾七娃同时可见。
- 角色继续采用原来的剪纸浮雕网格。将其改为自由绕拍的全立体角色涉及新拓扑、重绘背面乃至重新绑定，不属于这次无破坏精修。
- 复现：保存一份 `1aa855b` 基线工作区；在单独工作区运行 `python tools/polish_model_assets.py <baseline> <working-tree>`（Pillow、NumPy）。播放器、浏览器模型库和仓库已有导出工具的使用方法见项目 [README](../../README.md)。影片与原声音轨不随该改动新增到仓库。
